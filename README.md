# 💍 HmariShadi - Matrimonial Flutter App

HmariShadi is a modern and responsive matrimonial mobile application developed using Flutter.  
The application is designed to help users find their perfect life partner through secure authentication, profile creation, and smart matchmaking features.

---

## ✨ Features

- 🔐 Login with OTP Authentication
- 🔑 Login with Password
- 👤 Multi-Step User Registration
- 🌙 Dark Mode & Light Mode Support
- 🖼 Beautiful Carousel Banner Slider
- 📱 Responsive Mobile UI
- ❤️ Match & Search Navigation
- 💬 Chat & Mailbox UI
- ✅ Form Validation & Error Handling
- ♻ Reusable Widgets & Clean Architecture
